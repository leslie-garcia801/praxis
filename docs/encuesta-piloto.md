# Encuesta final del piloto

Tres cuestionarios cortos, uno para alumnos, uno para supervisores y uno para las oficinas de vinculación. Están listos para copiar a Google Forms. Cada uno tarda menos de 5 minutos. La primera pregunta de cada uno es la que mide la meta de utilidad percibida del piloto (specs §12): **promedio ≥ 4.5**.

## Cómo calcular la métrica

1. Exporta las respuestas de cada formulario a una hoja de cálculo.
2. De cada grupo, toma **solo la pregunta 1** (escala de 1 a 5) y calcula el promedio.
3. Calcula el **promedio general** con las respuestas de los tres grupos juntas (suma de todos los puntos ÷ número de respuestas).
4. Reporta los tres promedios por grupo y el general, junto con el número de respuestas de cada uno. La meta es el promedio general **≥ 4.5**.

| Grupo | Respuestas | Promedio pregunta 1 |
| --- | --- | --- |
| Alumnos | | |
| Supervisores | | |
| Vinculación | | |
| **General** | | |

Un grupo con pocas respuestas (por ejemplo, solo dos oficinas) pesa poco en el general; por eso se reportan también por separado.

## Nota de anonimato

Las encuestas son **anónimas**. No pidas nombre, matrícula, CURP, edad, sexo ni número de afiliación (RNF-07). En Google Forms, **no actives** "Recopilar direcciones de correo electrónico" y no marques ninguna pregunta como obligatoria si pide datos personales. Las respuestas abiertas se leen en conjunto; no se citan con el nombre de nadie.

Escala de las preguntas cerradas: 1 = nada, 5 = muchísimo (o totalmente de acuerdo, según la pregunta).

## Encuesta para alumnos

**Introducción para el formulario:** Gracias por participar en el piloto de Praxis. Esta encuesta es anónima y toma menos de 5 minutos. No escribas tu nombre ni tu matrícula.

| # | Pregunta | Tipo y opciones |
| --- | --- | --- |
| 1 | En general, ¿qué tan útil te resultó la app para registrar tu servicio social o tus prácticas? | Escala 1 a 5 (1 = nada útil, 5 = muy útil). **Obligatoria** |
| 2 | ¿Qué tan fácil fue registrar tu entrada y tu salida con el QR o el código corto? | Escala 1 a 5 (1 = muy difícil, 5 = muy fácil) |
| 3 | ¿Te tocó registrar sin señal? Si sí, ¿qué tan bien funcionó que se guardara y se enviara después? | Opciones: No me tocó / Sí, funcionó bien / Sí, tuve problemas |
| 4 | ¿Los recordatorios (salida olvidada y bitácora del domingo) te sirvieron? | Opciones: Sí / Un poco / No / No los activé |
| 5 | ¿Qué tan fácil fue escribir y enviar tu bitácora semanal? | Escala 1 a 5 (1 = muy difícil, 5 = muy fácil) |
| 6 | Comparado con la hoja en papel, ¿cuánto tiempo te ahorró la app? | Opciones: Mucho / Algo / Igual / Me tomó más tiempo |
| 7 | ¿Con qué frecuencia viste tus horas y tu avance en la app? | Opciones: Todos los días / Cada semana / Casi nunca |
| 8 | ¿Qué teléfono usas? | Opciones: Android / iPhone |
| 9 | ¿Qué fue lo que más te gustó o te sirvió? | Respuesta larga, opcional |
| 10 | ¿Qué cambiarías o qué fue lo que más te costó trabajo? | Respuesta larga, opcional |
